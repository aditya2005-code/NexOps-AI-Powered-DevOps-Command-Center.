# Switch Integration

Switch is the collaboration and agent communication platform for NexOps.

## Status: Not yet implemented

Before implementing, verify:
1. Authentication mechanism (OAuth2, API key, webhook secret?)
2. Supported event types (messages, commands, webhooks?)
3. SDK availability and version (check https://github.com/sandbox-quantum/switch)
4. Rate limits and webhook retry policy
5. How agents post messages back to Switch channels

Do not implement until the above is confirmed from official docs.
